# 主画面 中日双语（中文 / 日本語）功能说明

## 1. 怎么用

标题栏第二行（`SQL Server 接続：` 左边）有 **「中文」** 和 **「日本語」** 两个按钮：

- 点「日本語」→ 主画面上的全部文字立即改成日语（按钮 / 分组标题 / 标签页 / 表格列头 / 右键菜单 / 状态栏 / 进度 / 运行日志 / 弹窗）。
- 点「中文」→ 立即切回中文。
- 选中的那个按钮高亮（深蓝色底 + 白色粗体），另一个保持暗色。
- 选择会被记住：`%APPDATA%\MSIFAITOOLS\ui-language.json`（内容例如 `{"Language":"ja"}`），下次启动直接按上次的语言显示。
- 环境变量 `MSIF_UI_LANGUAGE` 优先级最高（`ja` / `jp` / `日本語` = 日语，其它 = 中文），现场想固定日语时用它，不用改文件。

## 2. 实现方式（为什么中文不用改写成资源文件）

代码里的中文**照旧只写一份**，这份中文就是「翻译键」：

| 位置 | 作用 |
| --- | --- |
| `Services/UiText.cs` | 语言状态 / 读写设置 / 查表（完全一致 → 模板 → 原文） |
| `Services/UiText.Japanese.cs` | **中日对照表（唯一需要维护翻译的地方）** |
| `Form1.Localization.cs` | 按当前语言重刷主画面文字 + 两个语言按钮 + `ShowMessage` / `SetProgressText` 等统一入口 |
| `Form1.cs` | `AppendLog` / `SetStatus` 内部自动调 `UiText.Translate`，所以日志与状态栏的调用处不用改 |

查表规则（`UiText.Translate`）：

1. **完全一致**：`{"第 1 步 · 装配图部品入库", "第 1 段階・アッセンブリ図部品登録"}`。
2. **模板匹配**：对照表里带 `{0}` `{1}` … 的条目当正则模板用「固定部分 + 任意内容」去匹配动态拼接出来的整句，
   例如 `{"正在分解（共 {0} 个 PDF）...", "分解中（全 {0} 件の PDF）..."}` 能匹配
   `正在分解（共 12 个 PDF）...`；占位符支持两位数（`{10}` ～ `{25}`，汇总行会用到）。
3. 都匹配不上 → **原样显示中文**（漏翻不会报错、不会出现空白）。

## 3. 以后新增文字 / 补翻译

1. 照常写中文（日志 `AppendLog("…")`、状态 `SetStatus("…")`、弹窗 `ShowMessage("…", "提示", …)`）。
2. 打开 `Services/UiText.Japanese.cs`，把中文**一字不差**地照抄成键，补上日语值（动态部分用 `{0}` `{1}`…）。
3. 界面控件文字：在 `Form1.Localization.cs` 的 `ApplyLanguage()` 里加一行 `控件.Text = UiText.T("中文");`，
   同时把中文补进对照表。
4. 编译即可；漏了也不会坏，只是那一句保持中文。

自检（排查漏翻）：`UiText.HasTranslation("中文")`、`UiText.TranslationCount`。

## 4. 当前覆盖范围

已覆盖（主画面 Form1）：

- 标题栏：窗体标题、副标题、`Debug（显示分步执行面板）`、`部材名置換表…`、`AI 設定`、`SQL Server 接続：`、`接続① genpin` / `接続② MSIF` 及其 ToolTip。
- ① 输入设置 / ② 执行 / ③ 分步执行 / ④ 运行日志·分类结果 的全部分组标题、按钮、复选框、说明文字。
- 第 0 ～ 6 步按钮（步骤名来自 `CmdAnalysisSteps`，`CmdAnalysisStep.Label` 也走翻译，服务层日志里的步骤名同样跟着切换）。
- 标签页、分类结果表格列头（文件名 / 分类 / 判定依据）、分类统计（`未知` → `不明`）、两个右键菜单。
- 状态栏（就绪 / PDF：N 个 / 引擎：PdfPig x.y.z）、进度标签、`打开输出目录` 等。
- 主画面自己的运行日志、状态栏文字、全部 MessageBox（含多行动态拼接的确认 / 完成 / 警告框）。
- CMD 分析 / AI 分析 / 一括执行 的汇总行（`BuildSummaryText`）。

仍为中文（可按第 3 节的办法继续补，不动架构）：

- 其它子画面：`AiSettingsForm`、`PartBasicInfoForm`、`MemberNameReplacementForm`、`MemberNamePickerForm`、`MemberMappingDbSettingsForm`、`PdfPreviewForm`。
- 服务层（`Services/*.cs`）逐条过程日志：这些文字经 `AppendLog` 输出，只要在对照表里加同一条目就会自动变日语；文件很多（40 多个），需要时按业务分批补即可。
