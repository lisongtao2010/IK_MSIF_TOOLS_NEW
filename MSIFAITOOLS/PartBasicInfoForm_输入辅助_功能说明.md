# PartBasicInfoForm（部品基本信息画面）输入辅助 功能说明

> 所属项目：`MSIFAITOOLS`（.NET Framework 4.8 / WinForms / AnyCPU）
> 源文件：`PartBasicInfoForm.cs`、`PartBasicInfoForm.Designer.cs`、
> `PartBasicInfoForm.PartNameCandidates.cs`、`PartNameCandidatePopup.cs`、`MemberNamePickerForm.cs`
> 相关：`WindowLayoutHelper.cs`（窗口摆放）、`PdfPreviewForm.cs`（PDF 预览）
> 更新日期：2026-11-16

---

## 1. 一句话概要

「部品名」「部材名」两列不是靠死记硬背手打的：**部品名**一边打字一边弹出**输入法式的候补列表**
（不抢焦点、按数字键就选），**部材名**单击就打开**「选择部材名」窗口**（同样带编号、按数字键写回）。

| 列 | 触发方式 | 候选窗口 | 选择方式 |
|----|----------|----------|----------|
| 部品名（`colPartName`） | 在单元格里**打字** → 自动弹出；`F4` 手动开关 | `PartNameCandidatePopup`（**不抢焦点**） | `1`～`9` / `0`（第 10 项）、鼠标单击、`Esc` 关闭 |
| 部材名（`colMemberName`） | **单击**单元格（不进入普通编辑） | `MemberNamePickerForm`（非模态，可同时操作本画面） | `1`～`9` / `0`、鼠标单击、`Enter` 写入输入内容 |

## 2. 部品名：输入法式候补（`PartNameCandidatePopup`）

### 2.1 行为

| 操作 | 结果 |
|------|------|
| 在「部品名」单元格里打字 | 按已输入内容过滤候选项，**贴着这一格**弹出候补列表（单元格下面放不下就翻到上面） |
| `1`～`9` | 选第 1～9 项，写进编辑框，光标移到末尾（可以接着打字） |
| `0` | 选第 10 项 |
| 鼠标单击某一项 | 同上（窗口是 `WS_EX_NOACTIVATE`，点它不会把焦点从单元格抢走） |
| `Esc` | **只关候补列表**，不退出单元格编辑 |
| `F4` | 开着就收起，没开就按当前输入内容（可以为空）打开 |
| 数字超出候选数（例如只列了 2 项时按 `5`） | 不拦截，数字照常打进单元格（部品名 里本来就有数字） |
| 按住 `Ctrl` / `Alt` / `Shift` | 一律不拦截（复制、切换输入法等组合键照常） |

### 2.2 候选项从哪来（优先度 = 数字越小越靠前，列表右侧的灰色标识就是来源）

| 优先度 | 标识 | 来源 |
|--------|------|------|
| ① | `分割` | 备注里含「位置：」（`CmdCalloutPartSplitter.RemarkPositionPrefix`）的行 —— 部材名 是按圈号 / 位置 从零件图分割出来的，最可信 |
| ② | `AI` | 「部材名 AI 推荐」（`colMemberNameAi`）有值、且「部材名」为空或与推荐值相同（归一化比较）的行 |
| ③ | `DB` | 部材部品マスタ（SQLite「部材部品」表）里和本行「部材名」关联的部品名；本行没有部材名 时用整张表 |
| ④ | `表` | 表格里其它行已经填好的部品名（同一张图里通常反复用同样的几种） |
| ⑤ | `マスタ` | 部品マスタ（`部品マスタ\Tbl_部品マスタ.csv` 第 2 列，和「部品コード」自动推定用的是同一份） |

- 按**归一化后的部品名**去重（半角カナ / 全角英数 / 空白 / 大小写都算一样），先出现的写法为准 → 优先度高的来源优先。
- 过滤顺序：先「以输入内容开头」的（0 档），再「包含输入内容」的（10 档）；同档里短的在前，再按字典序 → 同一个输入内容每次顺序一样。
- 输入内容**已经等于**某个部品名 的完整写法时**不再弹列表**（选完不会立刻又冒出一堆别的名字）。
- 最多 10 项（`PartNameCandidatePopup.MaxCandidates`）。

### 2.3 什么时候收起

`Esc`、单元格编辑结束（`CellEndEdit`）、焦点离开表格（`Leave`）、滚动 / 改列宽、点别的按钮、
本画面失去激活（切到别的程序）、点「部材名」单元格进入内嵌编辑 —— 都会收起候选列表
（窗口本身不释放，下次直接复用）。

> 「部材名」和「部品名」共用同一个编辑控件：在「部材名」里按 F2 / 直接打字时**不弹**部品名候补
> （见 `IsMemberNameCellEditing` / `DgvParts_CellBeginEdit`）。

## 3. 部材名：选择部材名窗口（`MemberNamePickerForm`）

- 单击「部材名」单元格即打开（非模态：开着也能改别的格子 / 换行 / 看图纸），**不进入普通编辑**。
- 候补顺序：① 这一行「部品名」在置换表（SQL Server `genpin.dbo.T_M_MergeName`）里对应的置换后 →
  ② 这一格现在的值（拆开 `|`，方便改回原值）→ ③ 部材部品マスタ 的部材名 一览。
- 顶部输入框打字过滤（`↑` / `↓` 换项），列表里没有的名字打在输入框里按 `Enter` 直接写入；
  输入框为空时按 `Enter` 会先确认是否清空这一格。想打数字当关键字时按住 `Ctrl`。

## 4. 窗口摆放（与 PDF 预览成对显示）

由 `WindowLayoutHelper` 统一摆放，**只在新建窗口时摆一次**，之后保留用户拖动的位置：

| 屏幕数 | PDF 预览窗口 | 部品基本信息窗口 |
|--------|--------------|------------------|
| **≥ 2 块** | **主画面（Form1）以外的屏幕** —— 不和主画面挤在同一块屏上 | 主画面所在的屏幕 |
| 1 块 | 工作区**左侧**（约 55%） | 工作区**右侧**（约 45%，不小于 860px） |

- 「主画面」= 本画面的 `Owner`（由 `Form1.ShowPartInfo` 设为 `Form1`）；取不到时退回本画面自己。
- 详细规则见 `PdfPreviewForm_功能说明.md` 第 3 节。

## 5. 相关快捷键

| 按键 | 作用 |
|------|------|
| `F4` | 在当前「部品名」单元格上开关候补列表 |
| `Esc` | 关闭候补列表（候补列表没开时 = 取消单元格编辑） |
| `Ctrl + S` | 保存 |
| `Delete` | 未进入编辑时删除选中行（编辑中只删单元格文字） |
| `Enter` | 「选择部材名」窗口里写入输入内容 |
