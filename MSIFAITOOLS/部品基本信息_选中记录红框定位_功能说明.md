# 部品基本信息画面「选中记录 → PDF 红框闪烁定位」功能说明

> 所属项目：`MSIFAITOOLS`（.NET Framework 4.8 / WinForms / AnyCPU）
> 源文件：`PartBasicInfoForm.cs`、`PartBasicInfoForm.Designer.cs`、`PdfPreviewForm.cs`
> 更新日期：2026-11-18

---

## 1. 一句话概要

部品基本信息画面里**选中一行记录**（点任意单元格 / 用方向键移动）时，
旁边的 **PDF 预览画面**会自动翻到这一行的「页码」，并在图纸上找到这一行的
**部品図番 / 部品コード / 部品名**，用**红框闪 3 次**标出它的来源位置。

> 例外：选中的行是**特注品**（「特注」= 1，或「数据来源」= `CMD分析・特注品.json`）时**不闪**（见 §2）。

```
部品基本信息画面                                   PDF 预览画面
┌───────────────────────────┐              ┌───────────────────────────┐
│ 番号 部材名 部品名  … 页码 │  选中第 3 行 │  第 2/3 页                │
│  1   上ﾚｰﾙ  枠     …   2  │ ───────────► │   ┌───────┐               │
│  2   ｶﾊﾞｰ   枠     …   2  │              │   │ 部品表 │ ← 红框闪 3 次 │
│  3    …      …     …   3  │              │   └───────┘               │
└───────────────────────────┘              └───────────────────────────┘
```

## 2. 触发时机

| 操作 | 是否闪烁 |
|------|----------|
| 单击表格里的任意单元格（同一行内换格） | 只在**换到另一行**时闪（同一行只闪一次） |
| 单击最左侧的「行号」列（整行选中） | 换行就闪（同一行只闪一次） |
| 方向键 / 上下移动当前行 | 换行就闪 |
| 右键点某一行（先选中该行再弹菜单） | 换行就闪 |
| 显示部品基本信息时表格自动填充 / 保存后重新载入 | **不闪**（`_suppressGridEvents` 期间、且 `_lastFlashRowIndex` 重置） |
| PDF 预览窗口没打开 / 已被用户关闭 | 不闪，也**不会主动打开** |
| 行的「页码」为空 / 不是数字 / ≤ 0（手工追加的行） | 不闪 |
| 这一行的部品コード・部品図番・部品名 都为空 | 不闪 |
| 选中的行是**特注品**（「特注」= 1，或「数据来源」= `CMD分析・特注品.json`） | **不闪**（部品来自特注品 Excel 的部品表，图纸上不一定印着对应文字） |

- 闪的时候**只改预览画面上的红框，不动窗口**：不把预览窗口提到最前、不激活、不抢焦点 ——
  焦点与方向键始终留在部品基本信息画面，用户故意放到后面的窗口也不会被预览窗口盖住。
  预览窗口被别的窗口挡住时红框照样在它自己的画面里闪，要看就点一下预览窗口把它提到前面。
- 同一行的判定键是行号（`_lastFlashRowIndex`）；换图 / 重新载入 / 保存后重新载入都会重置成 -1。
- **特注品不闪**（`IsSpecialOrderPartRow`）：「特注」= 1 的淡粉色行、或「数据来源」= `CMD分析・特注品.json`
  （旧值 `CMD分析・tz.json` 也算）的行，选中时不闪红框 —— 这些部品来自特注品 Excel
  （`AiAppData\<図番>\特注品.csv`）的部品表，图纸上不一定印着对应的部品コード / 部品名，
  闪了多半找不到、或命中到别的部品上反而误导。这种行也记成「已处理」，同一行里换格不重复判断。

## 3. 在图纸上定位哪一段文字

`PartBasicInfoForm.CollectRowSourceKeywords()` 按下面的顺序准备候选文字
（少于 2 个字符的不用 —— 单个字符会到处命中）：

| 顺序 | 取的列 | 说明 |
|------|--------|------|
| 1 | 「部品図番」（`colPartDrawingNo`） | **第 1 优先**：这一行有部品図番 就用它定位 —— 图纸上印的是具体图番，比可能是模糊 CD（`MZA□968`）的部品CD 好认；图上少了 `-`（库 `HJ-1234` / 图纸 `HJ1234`）也能靠宽松匹配找到 |
| 2 | 「部品コード」（`colPartCode`，即部品CD `BuhinCd`） | 部品図番 为空、或图上找不到部品図番 时用它；含 `□` / `○`（可变位）时按宽松匹配找（见下表） |
| 3 | 「部品名」（`colPartName`） | 前两个都找不到时退而求其次 |

`PdfPreviewForm.FlashTextHighlight(页索引, 关键字)` 的匹配规则：

| 环节 | 规则 |
|------|------|
| 页 | 先翻到这一行的「页码」页（`页码` 是 1 起，预览是 0 起；越界时夹到有效范围） |
| 取文字 | 用 PdfPig 解析该页（惰性、按页缓存，和「选字」共用一个 `PdfTextSelectionModel`） |
| 归一化 | 两边都走 `JapaneseTextConverter.NormalizeWidth`（NFKC：全角英数 → 半角、半角片假名 → 全角）＋ 去掉全部空白，全角 / 半角 / 空格差异不影响命中 |
| 匹配范围 | 逐行（竖排页面逐列）拼成一串后 `IndexOf`，**不跨行** |
| 关键字优先 | 关键字按 1 → 2 → 3 的顺序，**第一个在当页命中的关键字立即采用**：有部品図番 就用部品図番，部品図番 命中就不会改用部品CD / 部品名 |
| 多行命中 | **按分数取最优**：数「这一行里还含有其它关键字的个数」，取最多的那一行（部品図番 + 部品CD + 部品名 都在 → 最像部品表里的那一行）；同分取最靠前的一行 |
| 宽松匹配 | **每个关键字**按原样找不到时，再做一遍**宽松匹配**：`□` `○` `〇` `◯` `△` = 可变位（匹配 **0 或 1 个字符**），字符之间允许夹 `-` `_` `/` `・` 等分隔符（最多连续 2 个），**关键字里自带的分隔符也可以缺省**，框选长度不超过「关键字长度 + 8」。例：库里 `MZA□968` → 图纸上 `MZA1-968` / `MZA1968` / `MZA968` 都能命中；库 `HJ-1234` → 图纸 `HJ1234` 也能命中 |
| 模糊 CD 不退化 | 某个关键字含可变位（`□` / `○` …）而宽松匹配也没命中 → **直接不闪**，不再退到后面的关键字（同族部品的部品名是共用的，退过去只会闪到别的部品上） |
| 矩形 | 命中字符的外接矩形，四周各留 1 PDF 点；像素 = PDF 点 × 当前缩放 |

## 4. 闪烁表现

| 项目 | 值 |
|------|-----|
| 外框 | 红色 2.5 像素线（`ARGB(255, 220, 20, 20)`），再外扩 2 像素 |
| 填充 | 淡红半透明（`ARGB(45, 230, 30, 30)`），让人一眼看到位置 |
| 频率 | 200 ms 翻转一次，共 6 次翻转 = **亮 / 灭各 3 次**（约 1.2 秒），结束后自动消失 |
| 位置 | 闪之前把红框滚到可见区域中央（计算方式与 Ctrl+滚轮缩放一致） |
| 绘制 | 直接画在 `picPage.Paint` 上（和文字选择的高亮同一层，不改 PDF、不生成临时文件） |
| 打断后 | 换行 / 再点别的行 → 立刻重新开始闪；换页 / 换文档 / 关窗口 → 立刻清掉 |
| 不影响 | 缩放、拖动、选字、清除选择都不影响闪烁（PDF 坐标不变，只有像素比例变化） |

## 5. 静默失败（找不到就什么都不做）

下面这些情况 `FlashTextHighlight` 返回 `false`，**不弹提示、也不改状态栏**：

1. PDF 预览窗口还没打开 / 已关闭；
2. 这一行没有「页码」（手工追加 / 老数据）；
3. PDF 打不开文字层（扫描件 / 加密文件 / PdfPig 解析失败）→ `_textDocument == null`；
4. 该页上找不到这一行的任何关键字（例如图纸上只印了圈号，没印部品名）；
5. 某个关键字含可变位（`□` / `○` / `〇` / `◯` / `△`）且宽松匹配也没命中 → **直接不闪**，不再退到后面的关键字。

> 每选一行都弹一个「找不到」提示会很吵，所以设计成静默失败；需要确认时可以把
> 这一行的「部品コード / 部品名」和图纸对照，或直接用预览窗口的「选字」功能查。

## 7. 已知限制

1. **定位精度取决于图纸上有没有这段文字**：只印了圈号（1・2・3…）而部品名 / 部品コード 都在外部表格里的行，找不到就不闪。
2. **同类文字重复出现时取「最像部品表的那一行」**：按「这一行里还含有其它关键字的个数」打分取最高分（同分取最靠前的一行）；仍可能与用户心目中的位置差一行（图纸本身没有唯一标识时无法再区分）。
3. **跨行的部品名不匹配**：关键字只在同一行（同一列）内匹配，名称被 PDF 折成两行的行可能找不到。
4. **不主动打开预览窗口**：用户关掉预览后选中记录不会闪，需要点【预览 PDF】重新打开。
5. **闪烁时不再前置预览窗口**：只改预览画面上的红框，不碰窗口的 z 顺序 / 焦点；预览窗口被主画面或别的窗口挡住时看不到红框，需要看就把预览窗口点一下提到前面（这是为了不打断用户正在看的窗口）。
6. 只影响显示：不改 PDF、不写数据库、不产生临时文件。
7. **特注品不闪**：「特注」= 1 / 数据来源 = `CMD分析・特注品.json` 的行选中时不会闪红框。想让这类行也闪，去掉 `FlashSelectedRowSource` 里的 `IsSpecialOrderPartRow` 判断即可（其余逻辑不变）。
8. **模糊部品CD 认不出时宁可不闪**：`MZA□968` 这类含 `□` / `○` 的部品CD 靠「宽松匹配」去找图纸上的 `MZA1-968`；图纸上确实没有这一族的任何写法时，这一行**不闪**（不会退到共用的部品名去闪同族别的部品，例如 `MZB○○963` 那一行）。**有部品図番 的行不受影响**（部品図番 第 1 优先，先用它定位）。

## 8. 验证要点

1. 打开部品基本信息画面（PDF 预览同时自动打开），点表格第一行 → 预览翻到该行「页码」页，红框闪 3 次、约 1.2 秒后消失。
2. 用方向键连续往下移动 → 每换一行闪一次；同一行内点左右不同的单元格 → 不重复闪。
3. 换到「页码」不同的行 → 预览自动翻页后再闪。
4. 选择「部品図番」为空的行 → 用部品CD / 部品名定位，仍能闪；「部品図番」有值的行 → 红框落在**部品図番**上（不是部品CD 那一列）。
5. 关掉预览窗口后再点行 → 不闪、不报错；【预览 PDF】重新打开后恢复正常。
6. 扫描件（无文字层）PDF → 不闪、不弹框、不影响选行 / 编辑 / 保存。
7. 中 / 日 界面切换后行为不变（本功能没有界面文字）。
8. 把别的窗口（例如记事本）盖在预览窗口前面，再点表格行 → 红框照样在预览画面里闪，但预览窗口**不会被拉到最前**（前面的窗口保持不动、焦点仍在表格）。
9. 选一行**特注品**（淡粉色行 / 「数据来源」= `CMD分析・特注品.json`）→ **不闪红框**；再选普通行 → 恢复正常闪烁。
10. 同一页上「部品図番」出现多处（例如图纸别处也写了一次图番）→ 红框落在**同时印着部品CD / 部品名 的部品表行**，而不是第一处。
11. 选一行为**模糊部品CD**（`MZA□968` / `MZB○○963` 这种含 `□` / `○` 的）→ 红框落在**自己那一行**（图纸上 `MZA1-968` 之类），不会闪到同部品名的另一种 CD 的行；图纸上完全没有这一族的写法时 → 不闪（但该行**有部品図番**时仍会用部品図番 定位、照常闪）。
12. 选一行「部品図番」形如 `HJ-1234` 而图纸上印的是 `HJ1234`（少了 `-`）→ 宽松匹配命中，红框照常闪。
