# 部品基本信息画面「全局只保留一个窗口」功能说明

> 所属项目：`MSIFAITOOLS`（.NET Framework 4.8 / WinForms / AnyCPU）
> 源文件：`PartBasicInfoForm.cs`、`Form1.cs`
> 更新日期：2026-11-18

---

## 1. 一句话概要

**部品基本信息画面（`PartBasicInfoForm`）全局只保留一个**：在【分类结果】里对不同图番
反复点【部品信息】/ 双击行 / Enter，都只是让**同一个窗口**切换显示内容（`ShowDrawing`），
不会在屏幕上堆出第二个部品基本信息窗口。

```
【分类结果】点【部品信息】（图番 A） → 打开 1 个部品基本信息窗口（A）
【分类结果】点【部品信息】（图番 B） → 还是那 1 个窗口，内容切成 B（不新开）
【分类结果】点【部品信息】（换了图纸文件夹） → 先关掉旧窗口（有未保存修改时会询问）再新建 1 个
```

---

## 2. 行为一览

| 操作 | 结果 |
|------|------|
| 第 1 次点【部品信息】/ 双击分类结果行 / 按 Enter | 新建 1 个部品基本信息窗口（`new PartBasicInfoForm(库路径)`） |
| 窗口已打开，再看别的图番 | **复用同一个窗口**，只 `ShowDrawing(新 PDF)` 换内容（原来那一行正在编辑的修改会先询问是否保存） |
| 窗口被最小化后再点【部品信息】 | 同一个窗口恢复成 `Normal` 并显示 |
| 窗口被用户关掉后再点【部品信息】 | 重新新建 1 个（关闭时已注销「当前画面」） |
| 换了图纸文件夹（= 换了一份库）再点【部品信息】 | 先 `Close()` 旧窗口（有未保存修改时询问保存），关掉后新建 1 个指向新库的窗口 |
| 换库时在「未保存」询问里点了**取消** | **不再新建**：保留旧窗口并把它提到最前，状态栏提示「切换数据库已取消：请先保存或关闭它」 |
| 关闭主画面 | 主体画面 `OnFormClosed` 里一并关闭部品基本信息窗口（引用丢了也会从已打开的窗口里找回来关掉） |

## 3. 实现

### 3.1 当前画面登记（`PartBasicInfoForm.cs`）

| 成员 | 作用 |
|------|------|
| `_currentInstance`（`private static PartBasicInfoForm`） | 「当前打开的部品基本信息画面」。**构造函数**里登记，`OnFormClosed` 里注销 |
| `FindOpenInstance()`（`internal static`） | 取现在打开的部品基本信息画面：先看 `_currentInstance`，引用丢了再从 `Application.OpenForms` 里把活着的那个找回来并重新登记；没有时返回 `null` |
| 构造函数结尾 | `FindOpenInstance()` 若返回**另一个**活着的画面，先 `Close()` 它（它自己有未保存修改时会询问），再 `_currentInstance = this` —— 这样即使以后有别的入口直接 `new`，也不会同时留下两个 |
| `OnFormClosed` | `ReferenceEquals(_currentInstance, this)` 时清成 `null`（下次打开会新建） |

### 3.2 主画面的打开流程（`Form1.ShowPartInfo`）

```
ShowPartInfo(item)
 ├─ form = PartBasicInfoForm.FindOpenInstance()        // 全局唯一：先取现有的
 ├─ 库路径不同？
 │    ├─ form.Close()                                   // 旧窗口有未保存修改时会询问
 │    ├─ 还没关掉（用户点了取消）→ 提到最前 + 状态栏提示 → return（不新建第二个）
 │    └─ 关掉了 → form = null
 ├─ form == null → new PartBasicInfoForm(库路径)
 │                  ├─ form.MainWindow = this
 │                  └─ TransferPreviewFormToPartInfo()   // 主画面已开的预览窗口移交过来（只在新建时）
 ├─ _partInfoForm = form
 ├─ form.FormClosed -= / += PartInfoForm_FormClosed      // 只挂一次
 ├─ form.ShowDrawing(item.FilePath)                      // 换图番 = 换内容，不换窗口
 └─ created || !form.Visible → form.Show()（最小化时先恢复 Normal）
```

- `PartInfoForm_FormClosed` 只在「关闭的正是 `_partInfoForm`」时才把字段清空
  （新建的窗口已经接替时不会把新引用一起清掉）。
- `Form1.OnFormClosed`（主画面关闭）：先取 `_partInfoForm`，为空 / 已释放时再
  `PartBasicInfoForm.FindOpenInstance()` 兜底，然后一起 `Close()` + `Dispose()`。

---

## 4. 注意点 / 已知边界

1. **窗口唯一 ≠ 状态唯一**：复用同一窗口切换图番时，窗口里的「选择部材名」面板会先关掉
   （`ShowDrawing` → `CloseMemberNamePicker`），避免把值写到下一个图番的行上。
2. **换库被取消时不强关**：保留旧窗口是对用户数据负责（他可能正在编辑旧库），
   这时点【部品信息】只会把旧窗口提到前面并提示，不会产生第二个窗口。
3. **PDF 预览窗口不在此约束内**：预览窗口依旧是「主画面 / 部品基本信息画面各一个、成对显示」，
   新建部品基本信息窗口时会把主画面已打开的预览窗口移交过去（`TransferPreviewFormToPartInfo`）。
4. **不改变保存 / 导出逻辑**：本功能只影响窗口的创建与复用。
5. **复用窗口切换图番被取消时**：窗口内容仍是原来的图番，主画面状态栏显示
   「已取消切换图番：部品基本信息画面保持原来的图番」（不会写成新图番，避免误以为已经切换）。

## 5. 验证要点

1. 在【分类结果】里选图番 A →【部品信息】，再选图番 B →【部品信息】：屏幕上仍然只有**一个**
   部品基本信息窗口，标题 / 図番 / 表格内容变成 B。
2. 重复快速点【部品信息】/ 双击同一行 / 按 Enter：不会出现第二个窗口，也不会每点一次就重新读一遍预览。
3. 把部品基本信息窗口最小化 → 再点【部品信息】：同一个窗口恢复并前置。
4. 关掉部品基本信息窗口 → 再点【部品信息】：重新打开一个（只有一个）。
5. 在部品基本信息里改一格（出现「未保存」标记）→ 换 PDF 文件夹 → 点【部品信息】：
   弹「未保存」询问；点**取消** → 窗口保留并前置、状态栏提示，**没有**第二个窗口。
   再点一次并选「保存」→ 旧窗口关闭、打开指向新库的一个窗口。
6. 关闭主画面：部品基本信息窗口与 PDF 预览窗口一起关闭，无残留窗口。
