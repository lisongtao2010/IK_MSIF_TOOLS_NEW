# 部品基本信息画面「追加行 / 插入行 的番号」功能说明

> 所属项目：`MSIFAITOOLS`（.NET Framework 4.8 / WinForms / x64）
> 源文件：`PartBasicInfoForm.cs`（`InsertBlankRow` / `ResolveNextPartNumber`）
> 更新日期：2026-11-20

---

## 1. 一句话概要

部品基本信息画面新增一行空白行时（【追加行】按钮 / 右键「在上方插入行」「在下方插入行」），
「番号」不再取**参照行的下一个**，而是 **表格里当前最大的番号 + 1**。

```
表格现有番号：1, 2, 3, 4
  选中第 2 行 →【追加行】
  新行番号 = 4 + 1 = 5        ← 以前是 3（和原来的第 3 行重号）
表格是空的 → 新行番号 = 1
```

---

## 2. 规则

| 项目 | 行为 |
|------|------|
| 「番号」 | 表格里所有行（不含 `IsNewRow`）的「番号」最大值 + 1；一行都没有 / 都不是正整数时为 `1` |
| 「页码」 | 仍沿用参照行（参照行 = 选中行；没有选中行时取当前单元格所在行；都没有时 `1`） |
| 作用范围 | 【追加行】按钮、右键菜单「在上方插入行」「在下方插入行」——三者都走 `InsertBlankRow`，规则完全一致 |
| 行号列（`colNo`） | 不受影响：`RenumberRows` 仍按画面顺序重排（画面第几行就显示几） |
| 行顺序 | 不变：新行插在参照行的上 / 下方，**不会**因为番号变大而挪到表格末尾 |
| 保存 | 不变：`SaveParts` 仍按「页码 + 番号 + 部品コード」查重（番号本身不要求连续、也不要求从 1 开始） |

---

## 3. 实现

| 位置 | 说明 |
|------|------|
| `PartBasicInfoForm.InsertBlankRow(bool above)` | 「页码」取参照行；「番号」= `ResolveNextPartNumber()` 的结果，然后 `dgvParts.Rows.Insert(...)` |
| `PartBasicInfoForm.ResolveNextPartNumber()` | 遍历 `dgvParts.Rows`，对每行 `int.TryParse(GetCellText(row, "colNumber"))` 求最大值 + 1（跳过 `IsNewRow`；没有有效值时返回 `1`） |

---

## 4. 验证要点

1. 表格番号 1,2,3 → 选中第 2 行 →【追加行】：新行番号 = `4`，位置在第 2 行下面（原来第 3 行往上挪）。
2. 表格番号 1,2,3 → 右键第 1 行 →「在上方插入行」：新行番号 = `4`（以前会算成 `2`）。
3. 表格为空 →【追加行】：番号 `1`、页码 `1`。
4. 连续点两次【追加行】：番号依次 `4`、`5`（同一图番内不重号）。
5. 点【保存】后重新载入：番号按保存的值显示，`SaveParts` 的查重提示行为与以前一致。
